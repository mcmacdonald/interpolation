This script uses interpolation methods to smooth out population estimates for 5 or 10 year age groups into estimates for 1-year age groups. It includes code to calculate three linear, polynomial, and spline interpolation. For the function to work, the data must have one column named 'age' that consists of strings e.g., '0-4', '5-9', etc. and another column named 'pop' that lists numeric data.

The link to the original data from the Census of Population: https://www150.statcan.gc.ca/t1/tbl1/en/tv.action?pid=1710000501
